# 04 — Escalation tools (DRAFT)

Ladder built into every generator: **merchant letter → payment dispute → regulator complaint → small claims.**

| Tool | Legal hook | Deadline to show | Demand (Ahrefs US) | Notes |
|---|---|---|---|---|
| Refund / return request letter | Store policy; state disclosure law | Brand window from the DB | Brand-led (see 01) | Embedded on brand pages |
| "Order never arrived" letter | 16 CFR 435 | 30 days if no date stated | — | High pain, fits Temu/Shein/TikTok |
| Credit-card chargeback letter | Reg Z §1026.13 | 60 days from the statement | "chargeback" 11k; "how to file a chargeback" 250 | Explain the network vs. federal-law split |
| Debit / PayPal / BNPL dispute | Network rules / PayPal Purchase Protection / provider ToS (**not** Reg E for merchant disputes) | Per provider: ⚠ fetch PayPal, Klarna, Afterpay terms | "paypal chargeback" 1k; "klarna refund" 50; "afterpay refund" 10 | BNPL is a small search vertical, so build one hub page |
| Subscription cancellation letter | ROSCA; state auto-renewal laws (e.g. CA B&P §17602 ⚠) | — | cancel-[service] 5–34k each | **Go.** Partners: Rocket Money, Privacy.com |
| Airline refund demand | 14 CFR 260 | 7 business / 20 calendar days | AA 8.2k, United 2.2k | The exit screen goes to a claim firm (EU/UK flights) |
| Marketplace claim (A-to-z, eBay MBG) | Platform terms | Platform deadlines ⚠ fetch | eBay MBG 3.5k; A-to-z 200 | |
| Demand letter (pre-small-claims) | State law | State small-claims limit | "demand letter template" 1.8k, KD 16 | The best standalone generator keyword |
| Regulator complaints | FTC ReportFraud, CFPB, state AG, DOT | — | — | Template plus a link to the official form. **We never file on the user's behalf.** |
