## Product Return Resources

### Returning an Item

We kindly ask that you bring your item(s) to the store in as much of an original state as you are able to get them, including any packaging, manuals, or accessories you have retained.

### Assembled Items

We kindly ask that you ensure that products such as 3D Printer that you're returning are disassembled and in like-new condition, repackaged in the original box with all packaging and accessories.

### Data Removal

Please make sure that all data has been removed and that the device is no longer linked to any cloud account or to any other device so that we may accept the return of this product.

### Refunds

Refunds usually take anywhere from 5-14 business days. Credit Card transaction usually take about 5 business days while Debit Card transactions take about 14 business days.

## 15 Day Return Policy

## Products Not Eligible For Return

The following products are not eligible for return:

*   Earbuds\*
*   Trading Card Games
*   Damaged Drones
*   Opened software such as Microsoft Office, Microsoft Windows, Microsoft Windows Server, and Microsoft Windows Server clients\*\*
*   Electronic software downloads
*   Point of Sale Activation Cards that have a dollar value
*   Micro Center Gift Cards (except as required by law)
