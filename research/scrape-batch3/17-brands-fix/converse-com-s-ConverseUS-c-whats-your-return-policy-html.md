# What is Converse's return policy?

Body

At Converse, we’re not happy unless you’re happy! We have a **30-day return** period when returned to [Converse.com](http://converse.com/), and a **30-day** return period when returned to a store.

    
[Converse.com](http://converse.com/) offers free returns within the continental US. You can start the process by clicking the [**Start a Return**](https://returns.narvar.com/converse/returns?locale=en_US)

  
 **Converse By You** orders are made **custom** for you by you, and are **ineligible for returns or exchanges**.  If your item is **defective** or **flawed**, please check use this link “[Do Converse sneakers have a warranty](https://converseconsumerservices.my.site.com/s/article/do-converse-sneakers-have-a-warranty)” for next steps to make it right.
