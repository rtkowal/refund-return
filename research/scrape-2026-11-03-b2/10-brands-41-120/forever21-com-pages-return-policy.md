# Return Policy

_Updated April 1, 2025_

**Important Information About Returns, Gift Cards and Rewards**

**As a result of the change in ownership, all returns, gift cards, store credits, and rewards issued before May 1, 2025, will no longer be accepted on our site.**

If an item you ordered does not turn out to be what you expected, eligible items may get returned within 30-days from receipt for a refund. Refunds will be credited to the original form of payment for the net price after discounts and/or coupons- no exceptions. We will apply the following rules to process your return:

*   Returns are accepted for a refund within 30-days of receipt.
    
*   Any original shipping cost incurred will not be refunded.
    
*   All returned merchandise will incur a return shipping fee of $9.99 per return.
    
*   Merchandise should be in the same condition as when it was received and should be unworn, undamaged, unwashed, and sealable, with original tags attached, and all packaging materials included.
    
*   Beauty products may be returned if they are unopened, unused, and the original cellophane is fully intact.
    
*   We reserve the right, at our sole discretion, to determine if returned merchandise is in saleable condition.
    
*   All customers are responsible for the return shipping fees per the schedule below. Forever 21 will provide you with a shipping label in the return process and the fee will be deducted from your return refund amount.
    
*   Furniture, mattresses, wall art, mirrors, lamps, and artificial trees may incur a 15% restocking fee of the purchase price in addition to the $9.99 return shipping fee.
    

Certain items are Non-Returnable and Non-Refundable:

*   Items marked “Final Sale”.
    
*   Clearance items.
    
*   Furniture. If the item arrived damaged upon delivery, do not accept the delivery. If you accept the delivery, you shall be responsible for return shipping costs.
    
*   Individual parts of a Bundle: “2 for $50” unless you return the entire bundle.
    
*   Items that have already been assembled by you.
    
*   Altered apparel, special orders, cloth face mask coverings, perishable or personalized/monogrammed items, and items identified as "final sale" cannot be returned.
    
*   Intimates such as lingerie, swimsuits and undergarments, etc.
    

For the following conditions the return shipping fee and/or restocking fee will be waived:

*   The item was damaged in the initial shipping process.
    
*   An incorrect item was shipped by us; or
    
*   We shipped a defective item.
    

**Exchange Policy**

We currently do not offer direct exchanges. If you’d like a different size or color, simply place a new order for the item you need. Once we receive your returned item, we’ll issue a refund to your original payment method.

**How to return?**

Please use our fast & easy **[Returns Center](https://returns.forever21.com/#/)**

If for any reason you are unable to use the return portal, please contact Customer Service by email **support****@forever21.com**

*   A return shipping label will be provided.
    
*   If you are returning multiple items from a single order, you may be required to create shipping labels for each item. You can do so by going through the return portal for each item you are requesting to return.
    

**Can I return more than one order together?**

No, orders cannot be combined into a single return shipment. Please use the individual return label provided for each order, as each return must be processed separately.

**Returns Using Your Own Shipping Label**

If you choose to return an item using your own shipping label instead of the prepaid return label provided, you are responsible for ensuring the return is properly tracked. You must contact us and provide the return tracking number so we can identify and process your return upon arrival.

Refunds are issued only after the returned item is received and inspected at our warehouse. Returns sent without a tracking number may not be identifiable once received, which can result in delays or the inability to process a refund.

For timely and accurate return processing, we strongly recommend using the prepaid return label provided with your return authorization.
